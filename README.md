# Suhyeong Park — Personal CV Site

A lightweight static portfolio built for GitHub Pages. No build step or dependencies are required.

## Preview locally

Open `index.html` directly in a browser, or serve this directory with any static file server.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example, `suhyeong10.github.io`).
2. Push the contents of this folder to the repository's `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

## Update content

- Main page content: `index.html`
- Colors and layout: `styles.css`
- Theme toggle and reveal effects: `script.js`
- Downloadable CV: `assets/Suhyeong-Park-CV.pdf`
